# Learning route

How can a quantum algorithm count the levels that cross an energy threshold after a low-rank perturbation? The learning route follows the count from a two-dimensional example to a query bound that depends on the balance of the update's signs.

| Start here | What it covers |
| --- | --- |
| [Worked example](WORKED_EXAMPLE.md) | Compute an upward crossing, then see how two signed paths cancel. |
| [Textbook bridge](NIELSEN_CHUANG_BRIDGE.md) | Review the foundations for coherent queries, success flags, and counting. |
| [30 milestones](MILESTONES.md) | Follow the common map through the prerequisites, algorithm, and matching lower bound. |
| [Scientific account](../science/README.md) | Consult the model, statements, proofs, and resource accounting. |

The educational anchor is Michael A. Nielsen and Isaac L. Chuang, *Quantum Computation and Quantum Information*, 10th Anniversary Edition. [Cambridge University Press](https://www.cambridge.org/highereducation/books/quantum-computation-and-quantum-information/01E10196D0A682A6AEFFEA52D53BE9AE).
